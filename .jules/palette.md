## 2025-03-16 - Hidden Action Buttons Break Keyboard Accessibility
**Learning:** A recurring accessibility issue in this app's components is that action buttons (like edit/delete) on list items are often hidden by default (`opacity-0`) and only revealed on mouse hover (`group-hover:opacity-100`). This breaks keyboard accessibility because the buttons are invisible to keyboard-only users navigating via tab. Furthermore, these icon-only buttons (using emojis or SVGs) often lack `aria-label` attributes, and the icons themselves aren't explicitly hidden from screen readers (`aria-hidden='true'`).
**Action:** Use `focus-within:opacity-100` on containers to reveal hidden buttons when focused. Always add explicit `aria-label`s to icon-only buttons, and apply `aria-hidden="true"` to the icons (SVGs or emojis) to prevent redundant screen reader announcements. Add visible focus rings (`focus-visible:outline-none focus-visible:ring-2`) for better keyboard navigation.
