## 2024-05-15 - Dynamic ARIA Roles in Toasts and Notifications
**Learning:** Screen readers announce toasts and notifications best when they use dynamic ARIA attributes: `role='alert'` and `aria-live='assertive'` for errors, and `role='status'` with `aria-live='polite'` for general/success updates. Furthermore, interactive icon-only elements (like an '✕' close button) must have an explicit `aria-label`, and the visual icon text should be hidden from screen readers using `aria-hidden='true'` to prevent duplicate or confusing announcements like "✕ button Dismiss toast".
**Action:** Always implement dynamic `role` and `aria-live` based on notification severity. Use `aria-hidden` aggressively on purely visual indicators in these components, ensuring the container or the button provides the accessible name.
