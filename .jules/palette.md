## 2023-10-27 - Custom Tooltips vs Native Title
**Learning:** Using a native HTML `title` attribute alongside a custom CSS-based visual tooltip creates a confusing double-tooltip experience for sighted mouse users. Furthermore, relying purely on `title` doesn't consistently announce state to screen readers. When fixing this by converting the `title` to an `aria-label`, the new label must include any visible text (like 'HQ') to comply with WCAG 2.5.3 (Label in Name), and the custom tooltip itself must be marked `aria-hidden="true"` to prevent redundant screen reader announcements.
**Action:** When implementing custom visual tooltips, always omit the native `title` attribute. Use descriptive `aria-label` attributes on the interactive element (ensuring they contain any visible text), and add `aria-hidden="true"` to the custom tooltip element to provide a clean, unified experience for both sighted and screen reader users.
